## Running a service

| Key | What it does |
|---|---|
| **← →** | Previous and next slide |
| **↑ ↓** | Previous and next item in the running order |
| A slide's hot key | Bring that slide up |
| **⌥⌘1** | Audience screens on and off |
| **⌥⌘2** | Stage screens on and off |
| **⇧⌘R** | Refresh Displays |
| **⌥⌘M** | Send Stage Message… |
| **⌘F** | Search |

## Slides

| Key | What it does |
|---|---|
| **⌘C**, **⌘X**, **⌘V** | Copy, cut and paste the picked slides |
| **⌘D** | Duplicate (in Edit) |
| **Delete** | Delete the picked slides, after asking |
| **⇧-click**, **⌘-click** | Pick a run of slides, or one more |

## Editing

| Key | What it does |
|---|---|
| **Space** | Play and pause the slide's timeline |
| **⌘T** | Split a clip on the timeline |
| **⌥⌘[**, **⌥⌘]**, **⌥⌘T** | Transition at the start, end or both ends of a clip |
| Arrows | Nudge the selected layers; with **Shift**, further |

## Files and windows

| Key | What it does |
|---|---|
| **⌘N** | New Presentation… |
| **⇧⌘N** | New Window |
| **⇧⌘I** | Import ProPresenter Files… |
| **⌥⌘I** | Import Slipity Files… |
| **⇧⌘E** | Export Slide as Movie… |
| **⌘,** | Settings |
