Slipity Pro's actions are in the **Shortcuts** app, and Siri can run them by name. Use them on their own, in a Shortcut of your own, or in an automation.

## Running a service

| Action | |
|---|---|
| **Next Slide**, **Previous Slide** | Step through the service. |
| **Go to Slide by Hot Key** | Bring up the slide with that hot key. |
| **Clear Screens** | Take layers off. |
| **Blackout** | Fade the screens to black and back. |
| **Hide or Show Slides** | Take the words off and put them back. |
| **What's on the Screens** | Say what's up now. |
| **Start Countdown**, **Stop Countdown** | Run a countdown. |
| **Make Look Live** | Switch Looks. |
| **Show Overlay** | Put an overlay up. |
| **Show Stage Layout** | Change a stage screen's layout. |
| **Send Stage Message**, **Clear Stage Message** | Talk to the platform. |
| **Play Audio Playlist**, **Stop Audio** | Run the music. |
| **Set Camera Framing** | Reframe a camera. |

## Building a service

| Action | |
|---|---|
| **New Service** | Make a playlist. |
| **Open Service** | Open one. |
| **What's in the Service** | Say what's in it. |
| **Add Song to Service**, **Swap Song in Service**, **Remove from Service** | Change the songs. |
| **Add Scripture to Service** | Add a passage. |
| **Add Canva Design to Service** | Add a Canva design. |
| **Add Pictures or Video to Service** | Add media from Photos or Files. |
